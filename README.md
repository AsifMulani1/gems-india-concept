# GEMS Education India — concept website

A working concept for the GEMS Education India brand site, built for discussion.
Open the live preview, or clone and open `index.html` — it is a single
self-contained file with every asset inlined, so it runs from the filesystem with
no build step and no server.

## What it covers

Eleven routes: home, our schools, school brands, about, leadership, life at GEMS,
news, careers, campus connect, contact, and a page per campus.

- The campus network drives the whole site. Counts, the India map, the school
  finder, the city pages and the careers board are all computed from one dataset,
  so adding or removing a school updates every figure on every page.
- A preview control on **Our schools** switches between today's network and a
  hypothetical fifty-campus one, to show the layouts hold at scale.

## Status of the content

This is a concept, not a live site.

- Brand names, curricula, campus cities, leadership names and titles are taken
  from GEMS' own published pages.
- Figures that GEMS has not supplied are marked on the page where they appear.
  The careers board carries illustrative sample roles, clearly labelled as such.
- Forms are front ends only. Nothing is submitted or stored.
- Not an official GEMS Education property. `noindex` is set and robots are
  disallowed so it cannot be confused with the real site in search.
